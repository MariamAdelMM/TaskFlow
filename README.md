TaskFlow 🚀

TaskFlow is a modern, high-performance task management application built with Flutter. It combines a clean, design-first user interface with robust features like real-time messaging, state management with Riverpod, and local persistence.

🎨 Design Philosophy
The UI was meticulously crafted using Stitch to prioritize a clean and intuitive user experience. You can view the full design prototype here: Design Link.

✨ Key Features
🛠️ Core Functionality
Splash Screen: A sleek animated entry point featuring a gradient background and explicit animations.

Authentication: Complete Login/Register flow with comprehensive TextField validation.

Task Management:

Create tasks with titles, descriptions, and multiple sub-entries.

Dynamic sorting by priority and title-based search functionality.

Swipe-to-delete (Dismissible) and tap-to-edit interactions.

Toggle task status between Done and Pending.

Profile Management: Dedicated profile screen with user details and secure logout functionality.

⚙️ Advanced Technical Highlights
State Management: Powered by Riverpod for a scalable and testable architecture.

Local Persistence: Integrated SharedPreferences to securely store authentication tokens and user preferences.

Real-time Engagement: Leverages Firebase In-App Messaging for seamless communication.

Dynamic Theming: Full support for Dark Mode with custom font configurations and dynamic switching.

🛠️ Tech Stack
Framework: Flutter & Dart

Backend & Messaging: Firebase

State Management: Riverpod

Local Storage: SharedPreferences

Design Tool: Stitch

🚀 Getting Started
Prerequisites
Flutter SDK installed

Firebase project configured
